## 项目简介
本项目以 STM32F103C8T6 为主控，基于 FreeRTOS 实时操作系统开发物联网终端。针对芯片仅20KB RAM的极限资源做堆栈裁剪与多任务调度优化；集成 DHT11 温湿度采集、ESP8266 MQTT 云端通信、本地人机交互、UniApp 远程控制能力，完成端‑云‑用完整物联网闭环。
系统经过7×24小时长时间压力测试，无 HardFault 异常，验证轻量级 RTOS 在低成本物联网终端上的工程落地可行性。

## 核心功能
1. **多任务数据采集**：DHT11单总线驱动，采集精度 ±1℃ / ±5%RH；通过 FreeRTOS 消息队列向显示、控制任务同步数据，避免阻塞传感器采集周期。
2. **非阻塞物联网通信**：UART驱动ESP8266，采用**状态机+空闲中断**实现AT指令非阻塞解析；基于 MQTT v3.1.1 协议接入OneNet平台，完成传感器数据上报、远程指令下发双向通信。
3. **本地实时交互**：EXTI外部中断处理按键，独立任务实现LED开关切换、报警阈值调整；交互任务优先级高于通信任务，保障本地人机交互零延迟。
4. **安全远程管控**：UniApp客户端使用HMAC‑SHA1鉴权调用OneNet物模型API，3s轮询同步设备状态；封装标准化接口完成远程设备控制，端到端指令延迟＜2s。
5. **系统可靠性保障**：集成动态内存监控，检测并规避堆溢出与内存泄漏；增加看门狗复位做故障兜底，整机7×24h连续运行无异常。

## 技术栈
|类别|技术细节|
|----|----|
|主控与RTOS|STM32F103C8T6、FreeRTOS（任务调度、消息队列、内存管理）|
|硬件外设|DHT11温湿度传感器、ESP8266‑01S、OLED显示屏、独立按键、板载LED|
|底层驱动|GPIO、UART(DMA+空闲中断)、EXTI外部中断、DHT11单总线时序驱动|
|物联网协议|MQTT v3.1.1、OneNet物模型协议、HMAC‑SHA1鉴权加密|
|应用开发|UniApp(Vue3)、HBuilder X，支持小程序/APP双端访问|
|工具链|Keil MDK、STM32CubeMX、Git|

## 项目亮点
- **RTOS小资源极致优化**：20KB RAM硬件限制下合理分配4路核心任务堆栈；依靠动态内存监控定位消除内存泄漏，为同级别低成本MCU移植FreeRTOS提供可参考范式。
- **高性能非阻塞通信架构**：舍弃delay阻塞式AT解析，采用状态机+环形缓冲区设计，通信任务耗时降低90%，解决网络超时带来的传感器漏采集问题。
- **完整安全通信链路**：设备端MQTT Token生成 + APP端HMAC‑SHA1鉴权，全链路身份校验，避免明文传输敏感参数。
- **量化稳定性验证**：7×24h压力测试无HardFault故障，远程指令延迟稳定＜2s；软硬件方案完整，可直接复用为嵌入式物联网中级实战原型。

## 使用部署说明
1. 使用Keil MDK打开`设备端STM32详细代码`工程，编译烧录至STM32；修改WiFi配网信息、OneNet设备ID、鉴权密钥。
2. HBuilderX打开`APP详细代码`UniApp工程，配置OneNet平台鉴权参数，编译运行小程序或APP。
3. 参照`烧录和调试接线图.pdf`完成硬件接线，即可完整运行整套系统。

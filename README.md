# STM32环境监测与远程控制智能家居系统

## 项目简介
基于 STM32F103C8T6 单片机开发的物联网智能家居闭环控制系统，搭载 DHT11 温湿度传感器、ESP8266 WiFi 模块，对接 OneNet 物联网云平台；实现环境温湿度采集、本地 LED 按键控制、云端数据上报、手机端远程监控与设备指令下发，形成**本地手动控制 + 远程小程序/APP 控制**完整业务闭环，解决传统家居只能本地操作、无远程监测管控的痛点。

## 核心功能
- 环境监测：DHT11 单总线采集温湿度，采集精度温度±1℃、湿度±5%RH
- 本地控制：配置 GPIO、EXTI 外部中断，实现按键手动切换 LED 开关状态
- 云端通信：串口 UART 驱动 ESP8266，基于 AT 指令配网联网，稳定对接 OneNet 云平台完成传感器数据定时上报
- 远程交互：基于 HBuilder X 开发配套 UniApp 交互端，支持打包微信小程序/手机 APP
- 鉴权与控制：采用 HMAC-SHA1 加密生成鉴权 Token，调用 OneNet 物模型 API；3 秒定时轮询同步设备状态，封装接口实现 LED 远程开关控制，加入网络异常提示逻辑保障交互流畅

## 技术栈
- 主控芯片：STM32F103C8T6
- 硬件外设：DHT11 温湿度传感器、ESP8266 WiFi 模块、板载 LED、独立按键
- 底层技术：GPIO、UART 串口、EXTI 外部中断、单总线时序驱动
- 通信协议：AT 指令、MQTT、OneNet 物模型协议、HMAC-SHA1 加密鉴权
- 开发工具：Keil MDK、HBuilder X、OneNet 物联网云平台

## 项目亮点
- 完整物联网全链路设计：STM32 采集 → ESP8266 传输 → OneNet 云端存储 → UniApp 远程展示与控制
- 嵌入式底层模块化开发，外设驱动、通信逻辑解耦，代码可复用性强
- 交互端加入加密鉴权、定时轮询、网络异常处理，保证通信安全与使用稳定性
- 整套系统运行可靠，满足智能家居基础监测与远程控制需求，可作为物联网嵌入式入门实战项目框架

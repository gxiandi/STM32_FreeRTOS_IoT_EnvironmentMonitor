# STM32环境监测与远程控制智能家居系统

## 项目简介
基于STM32F103C8T6搭建的物联网闭环控制系统，实现本地环境监测与远程APP控制，解决传统家居单一控制痛点，实现了本地手动控制+远程APP查看/控制的完整闭环。

## 核心功能
- 温湿度采集与本地控制：DHT11采集温湿度（温度±1℃，湿度±5%RH），GPIO控制LED状态
- 远程数据上报：通过UART驱动ESP8266，基于AT指令联网，将数据上报OneNet云平台
- APP远程控制：开发配套UniApp交互端，使用HMAC-SHA1鉴权调用OneNet API，实现LED远程控制，指令延迟<2s

## 技术栈
- 主控：STM32F103C8T6
- 外设：DHT11温湿度传感器、ESP8266 WiFi模块、LED指示灯
- 协议：UART、AT指令、HTTP/OneNet物联网协议
- 开发工具：Keil MDK、STM32CubeIDE、OneNet云平台

## 项目亮点
- 完整的物联网闭环架构，从数据采集、传输到远程控制全流程实现
- 稳定的网络通信与数据上报机制，保证数据上报稳定可靠
- 为后续智能家居开发提供了可复用的硬件与软件框架
